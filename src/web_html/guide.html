이 문서는 views/guide.py 에서 자동 생성되었으며, 본문의 설정 수치는 기본값 기준입니다. 실제 값은 앱의 환경 설정 화면에서 확인·변경하세요.

전체 흐름: ① 환경 설정 → ② 수집 → ③ 후보 검토(승인/거절) → ④ 이메일 편집 → ⑤ 메일 창 열기

① 환경 설정 (왼쪽 메뉴 ⚙️ 환경 설정)

처음 한 번만 맞춰 두면 됩니다. 값은 이 컴퓨터의 config.yaml에 저장되고, 저장 버튼을 눌러야 반영됩니다.

설정을 바꿔도 다시 수집할 필요가 없습니다. 후보 리스트는 이미 저장된 기사를 새 설정으로 바로 다시 계산합니다.
(단, 수집 기간을 늘리거나 사이트를 추가했다면 다시 수집해야 새 기사가 들어옵니다.)

② 수집 (📰 후보 리스트 → 🔄 지금 수집)

켜져 있는 사이트를 동시에 읽어 기사를 저장합니다. 이미 저장된 기사(같은 주소)는 건너뛰므로 여러 번 눌러도 중복되지 않습니다.

  1. 기간 제한 — 발행 시각이 최근 3일보다 오래된 기사는 버립니다. 발행 시각이 없는 기사는 수집 시각을 기준으로 합니다.
  2. 주소 정리 — utm_ 같은 추적 파라미터, # 뒷부분, 끝의 /를 정리해 같은 기사를 하나로 인식합니다.
  3. 본문 추출 — 새로 들어온 기사만 본문을 가져와 앞에서 1500자까지 저장합니다. 사이트의 robots.txt가 막은 곳과 Google 뉴스 링크(중계 주소)는 건너뛰며, 그럴 땐 RSS 요약을 씁니다.
  4. 사이트 오류(예: HTTP 403 차단)는 화면에 경고로 표시되고 나머지 사이트는 계속 수집합니다.

저장된 기사는 30일(수집 기간이 더 길면 그 기간)이 지나면 정리되며, 승인한 기사는 지워지지 않습니다.

③ 후보 선정 기준 (이 앱이 기사를 고르는 방법)

수집된 기사는 아래 5단계를 순서대로 거쳐 후보가 됩니다. 화면을 열 때마다 현재 설정으로 다시 계산됩니다.

단계 1. 제외 키워드로 거르기

  • 제목 + RSS 요약에 제외 키워드가 하나라도 들어 있으면 후보에서 뺍니다. (현재 제외어: 광고, 포토, 부고, 인사)
  • 대소문자는 구분하지 않고, 글자가 포함되기만 하면 일치로 봅니다. 예: 제외어 인사는 "인사말", "인사이트"에도 걸립니다. 너무 짧은 단어는 주의하세요.
  • 설정의 본문에서도 제외 키워드 찾기를 켜면 추출한 본문까지 검사합니다.
  • 제외된 기사는 후보 리스트의 제외된 기사 보기에서 어떤 단어 때문에 빠졌는지 확인할 수 있습니다.
  • 이미 승인한 기사는 나중에 제외어를 추가해도 빠지지 않습니다.

단계 2. 같은 사건 기사 묶기

  • 여러 매체가 같은 소식을 쓰면 한 덩어리(묶음)로 합칩니다. 목록에는 묶음마다 대표 기사 1건이 나오고, 나머지는 관련 N건으로 보입니다.
  • 제목의 3글자 단위 조각이 얼마나 겹치는지(제목끼리, 또는 제목+요약 앞 200자끼리)를 0~1로 계산해 0.5 이상이면 같은 묶음입니다. 값이 낮을수록 더 많이 묶입니다.
  • 묶음 안의 어느 기사와 비슷해도 합류합니다.
  • 한계: 글자 기반이라 한국어 기사와 영어 기사는 같은 사건이어도 묶이지 않습니다.
  • 대표 기사는 ① 이미 승인한 기사 → ② 포함 키워드 점수가 높은 기사 → ③ 본문이 긴 기사 → ④ 최신 기사 순으로 고릅니다.

단계 3. 묶음별 점수 계산 (0~100점)

점수는 세 가지 부분 점수의 가중 평균입니다. 현재 가중치는 신선도 0.4 : 키워드 0.4 : 화제성 0.2이며,
합계가 1이 아니어도 비율로 자동 환산됩니다. (현재 비율 = 신선도 40% · 키워드 40% · 화제성 20%)

점수 = (신선도×가중치 + 키워드×가중치 + 화제성×가중치) ÷ 가중치 합계

부분 점수계산 방법
신선도묶음에서 가장 최근 기사 기준. 방금 나온 기사는 100점, 수집 기간(3일 = 72시간)이 다 지났으면 0점으로 시간에 비례해 줄어듭니다. 예: 기간이 3일이면 하루 지난 기사는 약 67점.
키워드포함 키워드가 제목에 있으면 그 키워드의 가산점 전부, 요약·본문에만 있으면 절반을 더합니다. 같은 키워드는 기사당 한 번만 셉니다. 묶음 안에서 가장 높은 기사 값을 쓰고 100점이 상한입니다. 포함 키워드가 하나도 없으면 0점입니다.
화제성같은 사건을 다룬 기사 수와 매체 수. (기사 수 − 1) × 20 + (매체 수 − 1) × 15, 상한 100점. 한 곳만 쓴 기사는 0점, 3개 매체가 쓰면 70점입니다.

예시: 제목에 가산점 10짜리 키워드 2개가 들어 있으면 키워드 20점, 2개 매체가 쓴 1시간 전 기사(기간 3일)라면
신선도 약 99 · 화제성 35 → 비율 4:6:2 기준 점수 ≈ (99×4 + 20×6 + 35×2) ÷ 12 ≈ 49점.

💡 키워드 점수의 영향이 큽니다. 가산점이 작게(예: 10점) 잡혀 있으면 키워드 부분 점수가 낮아서 신선도·화제성이 순위를 좌우합니다. 특정 주제를 확실히 우대하려면 그 키워드의 가산점을 올리거나(예: 30~50) 키워드 가중치를 높이세요.

단계 4. 후보로 올릴 묶음 자르기

점수가 높은 묶음부터 차례로 훑으면서 아래 조건을 통과하면 후보로 표시합니다.

  1. 점수가 최소 점수 20점 이상
  2. 그 묶음 대표 기사의 매체가 이미 5건을 후보로 올렸다면 건너뜀 (매체당 상한, 0이면 제한 없음)
  3. 후보가 최대 30건에 도달하면 중단

예외: 승인한 묶음은 항상 후보이고(개수에 포함되지 않음), 거절한 묶음은 후보에서 빠집니다.
후보 리스트의 후보만 보기를 끄면 기준에 못 미친 기사도 점수순으로 볼 수 있습니다.

단계 5. 사용자 검토

  • ✅ 승인: 이메일에 넣을 기사로 확정합니다. 묶음의 대표 기사에 기록됩니다.
  • 🚫 거절: 후보에서 뺍니다. 거절 취소로 되돌릴 수 있습니다.
  • 결정은 기사 단위로 저장되므로 설정을 바꾸거나 다시 수집해도 유지됩니다.
  • 점수 상세(신선도·키워드·화제성)는 각 항목의 본문 · 관련 기사 · 점수 상세에서 볼 수 있습니다.

결과가 마음에 안 들 때

증상조정 방법
원하지 않는 기사가 많다제외 키워드 추가, 해당 사이트 끄기, 최소 점수 올리기
원하는 주제가 아래쪽에 있다포함 키워드 추가/가산점 올리기, 키워드 가중치 올리기
같은 소식이 여러 줄로 나온다묶음 유사도를 낮추기 (예: 0.5 → 0.35)
전혀 다른 기사가 한 묶음이 된다묶음 유사도를 높이기
한 매체 기사만 가득하다매체당 최대 후보 수 낮추기
오래된 기사가 위에 있다신선도 가중치 올리기, 수집 기간 줄이기
후보가 너무 적다최소 점수 낮추기, 최대 후보 수 올리기, 후보만 보기 끄기

④ 이메일 보기·편집 (✉️ 이메일 보기·편집)

후보 리스트에서 ✉️ 이메일 만들기를 누르면 승인한 기사만 담은 초안이 만들어집니다.

  • 항목 구성: 분류 순서(AI → IT → 핫 이슈)로 정렬되고, 같은 분류 안에서는 점수 순입니다.
  • 요약 만들기: 추출한 본문(없으면 RSS 요약)의 앞쪽 문장부터 220자 안에서 잘라 넣습니다. AI가 쓴 요약이 아니라 기사 앞부분을 그대로 줄인 것이므로 어색하면 직접 고치세요.
  • 링크: 대표 기사 + 관련 기사를 항목당 최대 3개 넣습니다.
  • 편집: 왼쪽에서 제목·보내는/받는 사람·도입/맺음 문구와 항목별 포함 여부·제목·요약·링크를 고치면 오른쪽 미리보기에 바로 반영됩니다.
  • 💾 저장: 편집 내용을 저장합니다. 나중에 다시 열어도 유지되고, 승인 목록이 바뀌면 바뀐 항목만 추가·제거됩니다. 처음부터 다시 만들려면 🔁 초안 다시 만들기.
